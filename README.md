# Nurture

Consent-first blue-team prototype for local English word replacement. Each changed word gets a small `*`.

- **Website:** https://shubin123.github.io/nurture/ — working rule-based text demo and explicit browser tab picker with **local speech filtering**: the shared tab's audio is transcribed offline in a worker with Whisper tiny.en (weights committed in `docs/models/whisper-tiny-en`, run by a small in-house runtime on ONNX Runtime Web; no API, key or online service), delayed a few seconds, and every word matched by your rules or enabled word lists is muted or beeped before you hear it. Captions show replacements with `*`. Shared pixels are not filtered.
- **Word lists:** [docs/lexicons/sources.json](docs/lexicons/sources.json) — cited plain-text sources, starting with the CMU [Offensive/Profane Word List](https://www.cs.cmu.edu/~biglou/resources/bad-words.txt) (Luis von Ahn's Research Group). To add another source, append an entry with `id`, `title`, `author`, `url` and `citation`, then run `npm run fetch-lexicons`; it is vendored verbatim with a checksum and appears in the page automatically. Users can also load a local `.txt` list for the session. Your explicit rules take priority, and a "Never filter" box removes entries (the CMU list includes identity and everyday terms such as *black*, *gay* or *church*).
- **Extension:** [installation instructions](extension/README.md) — explicitly enable replacements on an authorized current tab, with stop/restore controls.
- **Models:** [MODEL.md](MODEL.md) — balanced character-context and BERT Mini INT8 are the selected opt-in review tools. Original three research models remain archived. Automatic-filter precision gates are not met.
- **Results:** [measured comparisons](docs/reports/RESULTS.md), [7,000-comment browser evaluation](docs/reports/balanced-browser-evaluation.json) and [browser throughput](docs/reports/balanced-browser-benchmark.json).
- **Balanced-data experiment:** [protocol and limitations](ml/EXPERIMENTS.md). Browser negative-post false positives are 4.06% (character) and 3.88% (Mini); quotation errors persist. The character baseline processes approximately 418,000 useful tokens/s on the reference M4 warm workload, not a mobile or Internet-speed guarantee.
- **Plan:** [PLAN.md](PLAN.md) — milestones and trust boundaries. The earlier software-protection proposal is preserved in [PROTECTION.md](PROTECTION.md).

## Development

Serve locally with `python3 -m http.server 8000 --directory docs`, then open `http://localhost:8000`. Committed static artifacts run without installation. For development, run `npm ci`, `npm test`, `npm run build`, `npm run test:browser`, `npm run test:speech` and `npm run test:whisper` (with the server running). The speech test plays a committed clip through a faked tab picker; the Whisper conformance test compares the in-house runtime with `ml/whisper_reference.py` (log-mel and tokens) and with pauses measured in the audio (word timings). Re-fetch pinned assets with `npm run fetch-asr-model` and `npm run fetch-lexicons`. The extension's shared rule engine is copied from `docs/filter.js` with `npm run sync-filter` after edits.

Full training and evaluation commands are in [MODEL.md](MODEL.md). Python dependencies and JS packages are pinned. Raw data/checkpoints remain ignored; public quantized weights, self-hosted WASM, licenses and aggregate reports are committed. The character model is the throughput baseline; contextual models cost more memory and compute, and are not guaranteed to improve your filtering policy.

The website sends no form text or shared streams to a server, uses no analytics and stores no settings. Hosting receives normal asset requests; public model/runtime files may be cached by the browser. The home page is the tab viewer: pressing **Share a tab** opens the browser picker and loads the offline speech-to-text model (Whisper tiny.en) from this site, with a progress bar in the viewport. The model and WASM runtime are kept in the browser's Cache Storage (`nurture-speech-*`, replaced when the pinned files change; clear site data to remove), so later visits load in under a second without network; the delayed tab plays in the page with flagged words muted and captions overlaid. The text demo and classifier lab are on `lab.html`, where models load only after explicit download consent. Inference stays local in workers. Screen sharing requires browser permission. Speech filtering needs a tab share with "Also share tab audio" (Chromium); the source tab is silenced locally during sharing so only the delayed, filtered audio plays. Recognition can miss or mishear words, especially with music, crosstalk or accents, and long or fast speech may be caught late (the page reports this). This prototype does not guarantee complete filtering and does not censor video or images.
