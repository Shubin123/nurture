# Nurture

A proposed layered software-protection strategy: licensing, device identity, server-side controls, tamper resistance, optional media protection, detection and enforcement.

- Read the complete roadmap in [PLAN.md](PLAN.md).
- Preview the website locally: `python3 -m http.server 8000 --directory docs`, then open `http://localhost:8000`.
- The website has no dependencies, external fonts, tracking or build step.

## Publication

The repository is private. GitHub Pages is intentionally not enabled: a private personal repository does not guarantee a private Pages website. After explicitly accepting public website access and confirming account eligibility, configure Pages to deploy from `main` → `/docs`. For private Pages access, use an eligible GitHub Enterprise Cloud organization and verify access controls before publishing.

## Scope

This repository contains a proposal and a static presentation, not license enforcement code. All owners, timings and operating policies are proposals awaiting approval.
